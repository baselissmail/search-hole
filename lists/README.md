# First-party lists

Lists written and maintained by search-hole, licensed CC0-1.0 (see `LICENSE` here; ADR-0016).

| List | Kind | Where | What it does |
|---|---|---|---|
| `official-docs` | official | `packages/search-hole/src/lists/bundled/official-docs.ts` (bundled) | Marks official documentation sites as `official` in results and receipts; the default profile ranks them higher. Never hides anything. |

Contributing: add a public link showing the site is the project's own documentation (or, for block lists, evidence that a site is spam or a clone). Contributions are accepted under CC0-1.0 only.
