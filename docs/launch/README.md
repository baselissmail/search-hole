## Before posting anything

- [ ] The release is out, and installs from the public marketplace, npm and the `.mcpb` on macOS, Windows and Linux (docs/release.md step 7).
- [ ] Every claim below is still true for that release, especially the bracketed `[check: …]` notes and the "limits" paragraphs. Delete a claim rather than soften it.
- [ ] The README quickstart works for a newcomer exactly as written, and the hero GIF shows the current UI.
- [ ] The numbers you quote (tests, bundle sizes, setup time) come from that release, not from these drafts.
- [ ] Post one place at a time, and stay around for a few hours to answer questions. Same-day cross-posting reads as spam.
- [ ] Say that Claude Code helped build it. The commit history shows it, and people will ask.

## Tone

Plain and specific. What it does, how to try it in a minute, what it stores and where, and what it can't do. No "revolutionary", no "game-changer", and no comparisons with products you haven't measured. "Like Pi-hole, for AI search" is fine as a description of the idea, but never use Pi-hole's name or logo as branding (trademark, MASTER_PLAN §12.5).
